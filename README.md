# Company Inner Search App

社内文書検索システム

## Streamlit Cloud Deployment

This app is designed to run on Streamlit Community Cloud.

### Main Files
- `main.py` - Primary application file
- `app.py` - Alternative entry point for Streamlit Cloud

### Running the app
```bash
streamlit run main.py
```

### Configuration
- Python 3.8+
- See `requirements.txt` for dependencies
- OpenAI API key required (set in Streamlit Cloud Secrets)
